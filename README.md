# Activepieces Extension for Gemini CLI

Connect Gemini CLI to [Activepieces](https://www.activepieces.com/) through MCP to build, manage, and run automations using natural language.

## About Activepieces MCP

Activepieces is an open-source automation platform that lets you connect apps and automate workflows.

The Activepieces MCP server gives Gemini access to tools for creating, modifying, and managing your automations.

With it, you can:

- Execute tasks across your apps
- Create and modify automation flows
- List and manage existing flows
- Explore available integrations and actions
- Configure triggers and steps
- Manage tables and records
- Add conditional branches
- Publish flows
- Test runs

Authentication is handled securely through OAuth 2.0 with dynamic client registration.

[Learn more about Activepieces MCP](https://www.activepieces.com/docs/mcp/overview)

## Example use cases

### Automate repetitive tasks

> "Create a flow that triggers when a new row is added to Google Sheets, sends a Slack notification, and creates a task in Asana."

### Manage existing automations

> "List all my active flows and disable the one that sends daily email reports."

### Build multi-step workflows

> "Create a flow triggered by a new GitHub issue that categorizes it using AI, assigns it to the right team member in Linear, and posts an update in Slack."

### Change your automation logic

> "Add a conditional branch to my order processing flow. If the order total is over $500, send it for manual approval before processing."

### Explore available integrations

> "What pieces are available for CRM integrations? Show me the actions available for HubSpot."

### Execute tasks across your apps

> "Summarize the latest Doc in my Google Docs"

## Get started

Sign up for [Activepieces](https://www.activepieces.com/) and connect Gemini CLI to your Activepieces account.

For setup instructions, see the [Activepieces MCP documentation](https://www.activepieces.com/docs/mcp/overview).
